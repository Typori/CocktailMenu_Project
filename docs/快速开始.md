## 🚀 启动方式

### 方式一：一键启动（推荐）⭐

直接双击项目根目录下的 **`启动服务器.command`** 文件即可！

**特点：**
- 🎯 双击即可启动，无需打开终端
- 🌐 自动打开浏览器访问 http://localhost:5173
- 📦 自动检查并安装依赖
- 💡 显示友好的启动信息

**添加到 Dock 栏：**
1. 找到 `启动服务器.command` 文件
2. 拖动到 Dock 栏右侧（文稿区域）
3. 以后点击 Dock 图标即可启动

### 方式二：终端启动

```bash
cd /Users/typori_mac/codebuddy/Users/typori_mac/Documents/AI/CocktailMenu_Project
./start-server.sh
```

### 方式三：使用 npm 命令

```bash
# 首次使用需要安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 停止服务器

在终端窗口按 `Ctrl + C` 即可停止服务器

## 📖 首次使用指南

### 1️⃣ 添加原料（必须先做）

1. 点击左侧菜单"原料管理"
2. 点击右上角"添加原料"按钮
3. 填写原料信息：
   - **名称**：例如"金酒"
   - **英文名**：例如"Gin"
   - **分类**：选择"gin"
   - **价格**：例如180
   - **数量**：例如700
   - **单位**：选择"ml"
   - **酒精度**：例如40
   - **当前库存**：例如700
   - **最低库存**：例如200

💡 系统已经预置了一些示例原料，你可以直接使用或修改。

### 2️⃣ 创建配方

1. 点击"配方管理"
2. 点击"创建配方"
3. 填写基本信息：
   - **酒名（中文）**：例如"莫吉托"
   - **酒名（英文）**：例如"Mojito"
   - **制作步骤**：详细描述制作方法
   - **杯型**：选择合适的杯型
   - **风味标签**：选择风味特征

### 3️⃣ 查看酒单

1. 点击"酒单展示"
2. 可以切换网格/列表视图
3. 点击任意酒款查看详情
4. 在详情页可以左右滑动切换酒款

### 4️⃣ 管理库存

1. 点击"库存管理"
2. 查看当前库存状态
3. 使用 +10/-10 按钮调整库存
4. 或点击"补满"按钮补充到最大值

### 5️⃣ 查看数据分析

1. 点击"数据分析"
2. 查看总收入、总成本、利润率
3. 查看利润最高的配方排行
4. 可以导出数据或PDF菜单

## ❓ 常见问题

### Q: 双击启动文件没反应？
**A:** 首次使用可能需要在"系统设置 > 隐私与安全性"中允许运行

### Q: 提示权限错误？
**A:** 在终端运行：`chmod +x 启动服务器.command`

### Q: 端口被占用？
**A:** 
- 关闭其他占用 5173 端口的程序
- 或修改 `vite.config.ts` 中的端口配置

### Q: 数据丢失了怎么办？
**A:** 如果有备份的JSON文件，可以通过"设置"→"导入数据"恢复

### Q: 如何清空所有数据重新开始？
**A:** 进入"设置"→"清空所有数据"，需要二次确认

### Q: 为什么看不到配方的成本和酒精度？
**A:** 需要先添加原料，然后在配方中添加配料，系统会自动计算

### Q: 页面显示没有数据怎么办？
**A:** 如果升级后发现数据显示为空，不要担心，数据还在！这是查询问题：
1. 打开浏览器控制台（F12）
2. 运行命令：`await dbDebug.checkStatus()`
3. 如果看到数据，运行：`await dbDebug.fixDisplayOrder()`
4. 刷新页面即可恢复

### Q: 如何备份数据？
**A:** 
1. 打开浏览器控制台（F12）
2. 运行命令：`await dbDebug.exportData()`
3. 或者在"设置"页面点击"导出数据(JSON)"
