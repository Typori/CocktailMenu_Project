# 🌟 功能详解

> 本文档详细介绍 Cocktail Menu Pro 的所有功能模块。

## 📊 仪表盘 (Dashboard)

### 功能概览
- **统计卡片**：显示配方总数、原料种类、平均成本、平均利润率
- **收藏的配方**：快速访问你最喜欢的配方
- **库存警告**：显示需要补货的原料
- **快捷操作**：一键跳转到常用功能

### 使用场景
- 每天打开应用时的第一个页面
- 快速了解整体运营状况
- 发现需要关注的问题（如库存不足）

---

## 🍾 原料库存 (Ingredients)

### 核心功能

#### 1. 原料管理
- **添加原料**：中英文名称、分类、价格、数量、单位、酒精度
- **编辑原料**：修改任何原料信息
- **删除原料**：删除不再使用的原料
- **库存设置**：设置当前库存和最低库存阈值

#### 2. 原料分类
支持9种分类：
- 烈酒 (Spirit)
- 利口酒 (Liqueur)
- 其他酒类 (Other Alcohol)
- 香精 (Essence)
- 果汁 (Juice)
- 汽水 (Soda)
- 糖浆 (Syrup)
- 装饰品 (Garnish)
- 其他 (Other)

#### 3. 自动计算
- **单位价格** = (总价格 / 数量) × (1 + 损耗率/100)
- 例如：180元/700ml，损耗率5% = 0.27元/ml

#### 4. 库存管理
- **快速调整**：+10/-10按钮
- **补满功能**：一键补充到最大值
- **库存警告**：当前库存 < 最低库存时显示⚠️
- **进度条**：可视化库存状态

#### 5. 筛选和搜索
- **搜索**：支持中英文名称搜索
- **分类筛选**：按原料分类筛选
- **显示数量**：每个筛选项显示对应数量

### 界面特点
- 紧凑的卡片布局
- 颜色编码分类
- 响应式网格（xl屏幕显示4列）

- **颜色**：文本输入

- **酒精度**：自动计算（只读）

#### 2. 配料列表
- **添加配料**：从原料库选择
- **设置用量**：数量和单位
- **删除配料**：移除不需要的配料
- **表格布局**：统一的表头，紧凑排列

#### 3. 制作步骤
- **分步骤**：每个步骤独立编号

#### 4. 菜单信息
- **菜单名称**：支持多个版本
- **酒款描述**：详细描述
- **售价**：设置价格
- **酒精度**：显示自动计算的值

#### 5. 备注
- 记录制作心得
- 调整建议
- 特殊注意事项

#### 6. 图片管理
- **上传图片**：支持多张图片
- **预览图片**：点击查看大图
- **删除图片**：移除不需要的图片

### 配方查看器 (RecipeViewer)

#### 1. 完整信息展示
- 配方名称和基本信息
- 配料列表（含用量）
- 制作步骤
- 菜单信息
- 图片展示

#### 2. 图片预览
- 点击图片全屏查看
- 点击背景关闭
- 透明背景，响应式

#### 3. 操作按钮
- 编辑配方
- 删除配方
- 返回列表

### 自动计算功能

#### 容量计算
```
总容量 = Σ(配料体积)
只计算：ml、oz、cl
不计算：dash、piece
```

#### 酒精度计算
```
酒精度 = (总酒精体积 / 总容量) × 100%
总酒精体积 = Σ(配料体积 × 原料酒精度)
```

#### 成本计算
```
总成本 = Σ(配料用量 × 原料单价)
```

## 🧮 计算功能详解

### 1. 成本计算

**公式**：
```
配方成本 = Σ(配料用量 × 原料单价)
```

**示例**：
```
莫吉托配方：
- 白朗姆酒 50ml × 0.23元/ml = 11.5元
- 青柠汁 20ml × 0.06元/ml = 1.2元
- 糖浆 15ml × 0.04元/ml = 0.6元
- 薄荷叶 10片 × 0.1元/片 = 1元
总成本 = 14.3元
```

### 2. 酒精度计算

**公式**：
```
ABV = (Σ(配料体积 × 酒精度) / 总体积) × 100%
```

**示例**：
```
莫吉托配方：
- 白朗姆酒 50ml × 40% = 20ml纯酒精
- 青柠汁 20ml × 0% = 0ml
- 糖浆 15ml × 0% = 0ml
- 苏打水 100ml × 0% = 0ml
总体积 = 185ml
ABV = 20ml / 185ml × 100% = 10.8%
```

### 3. 利润率计算

**公式**：
```
利润率 = (售价 - 成本) / 售价 × 100%
```

**示例**：
```
售价：68元
成本：14.3元
利润率 = (68 - 14.3) / 68 × 100% = 79%
```

### 4. 单位换算

**支持的单位**：
- ml (毫升) = 1ml
- oz (盎司) = 30ml
- cl (厘升) = 10ml
- dash (少许) = 1ml
- piece (个) = 不参与容量计算

## 💡 使用技巧

### 1. 快速创建配方
1. 先添加常用原料
2. 使用复制功能创建相似配方

1. 使用单页模式展示给客人
