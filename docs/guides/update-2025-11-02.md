### 1. ✅ 图片预览统一优化
**实现内容：**
- 创建了通用的 `ImagePreviewDialog` 组件 (`src/components/ImagePreviewDialog.tsx`)
- 应用到所有显示图片的地方：
  - RecipeViewer（配方查看页面）
  - RecipeEditor（配方编辑页面）

- `bg-transparent` 和 `border-0` 实现透明背景
- `object-contain` 保持图片比例

### 2. ✅ 点击非图片区域关闭
**实现内容：**
- 在 `ImagePreviewDialog` 组件中添加了点击事件处理
- 点击图片本身不会关闭对话框
- 点击图片外的任何区域（背景）会关闭对话框

**技术细节：**
```typescript
onClick={(e) => {
  if ((e.target as HTMLElement).tagName === 'IMG') {
    e.stopPropagation();
  }
}}
```

### 3. ✅ 库存卡片紧凑布局
**实现内容：**
- 优化了 `Ingredients.tsx` 中的卡片布局
- 减小了各项间距和字体大小

### 4. ✅ 原料类型调整
**实现内容：**
- 更新了 `SpiritType` 类型定义
- 修改了分类配置和排序

**变更详情：**
- ❌ 移除：`wine`（葡萄酒）、`beer`（啤酒）、`fruit`（水果）、`beverage`（饮料）
- ✅ 新增：`other_alcohol`（其他酒类）、`soda`（汽水）
- ✅ 保留：`spirit`（烈酒）、`liqueur`（利口酒）、`essence`（香精）、`juice`（果汁）、`syrup`（糖浆）、`garnish`（装饰品）、`other`（其他）

**新排序：**
烈酒 → 利口酒 → 其他酒类 → 香精 → 果汁 → 汽水 → 糖浆 → 装饰品 → 其他

### 5. ✅ 损耗率计算Bug修复
**问题：**
- 之前默认损耗率为5%，即使用户设置为0也会按5%计算

**修复：**
- 修改 `calculateUnitPrice` 函数，默认损耗率改为 `0%`
- 公式：`单价 = (价格 / 数量) × (1 + 损耗率/100)`
- 现在损耗率为0时，计算结果正确

**文件：** `src/utils/calculations.ts`

### 7. ✅ Combobox Enter键确认功能
**问题：**
- 之前修复页面跳转时，把Enter键确认功能也禁用了

**修复：**
- 重写了 Combobox 组件的键盘事件处理
- Enter键现在会选择第一个匹配的选项
- 添加了搜索值状态管理
- 选择后自动关闭下拉菜单并清空搜索

**技术细节：**
```typescript
const handleKeyDown = (e: React.KeyboardEvent) => {
  if (e.key === 'Enter') {
    e.preventDefault()
    if (filteredOptions.length > 0) {
      onValueChange(filteredOptions[0].value)
      setOpen(false)
      setSearchValue("")
    }
  }
}
```
