## [1.0.1] - 2025-11-04

### 优化改进 🔧

#### 页面滚动布局优化
- **配方管理页面（Recipes.tsx）**
  - 实现固定顶部布局设计
  - 标题、搜索框、筛选按钮固定在顶部
  - 只有筛选器和配方列表参与滚动
  - 使用 `h-[calc(100vh-8rem)]` 计算容器高度
  - 使用 `flex-1 overflow-y-auto min-h-0` 实现可滚动区域

- **原料与库存管理页面（Ingredients.tsx）**
  - 应用相同的固定滚动布局
  - 固定区域包含：标题、操作按钮、排序提示、库存警告、搜索筛选
  - 可滚动区域包含：原料卡片列表
  - 响应式设计：移动端 `h-[calc(100vh-8rem)]`，桌面端 `md:h-[calc(100vh-7rem)]`

- **上架酒款管理页面（VenueManagement.tsx）**
  - 实现固定滚动布局
  - 解决 Tabs 组件嵌套导致的布局失效问题
  - 将 TabsList 放在固定顶部区域
  - 将 TabsContent 放在可滚动区域
  - 固定区域包含：标题、店面标签页、编辑删除按钮
  - 可滚动区域包含：操作栏、搜索、筛选器、酒款列表

- **配方预览页面（RecipeViewer.tsx）**
  - 优化顶部按钮布局
  - 移除左上角固定返回按钮，避免与导航栏重合
  - 将返回按钮整合到内容区域的顶部
  - 保持操作按钮（收藏、复制、编辑）的可访问性

#### 布局设计规范统一
- 建立统一的固定滚动布局模式
- 使用 Flexbox 实现垂直布局分区
- 固定区域使用 `flex-shrink-0` 防止压缩
- 滚动区域使用 `flex-1 overflow-y-auto min-h-0` 确保正确滚动
- 响应式高度计算适配不同屏幕尺寸

### 修复 🐛

#### Tabs 组件布局问题
- **问题**：在 VenueManagement 页面中，Tabs 组件嵌套导致固定滚动布局失效
- **原因**：TabsContent 在可滚动区域外，导致整个 Tabs 组件参与滚动
- **修复**：重新调整布局结构，将 TabsList 和 TabsContent 分离到不同的布局区域
- **文件**：`src/pages/VenueManagement.tsx`

#### JSX 标签闭合错误
- **问题**：`Expected corresponding JSX closing tag for <TabsContent>`
- **原因**：缩进错误和多余的 `</div>` 标签
- **修复**：修正所有标签的缩进，移除多余闭合标签
- **文件**：`src/pages/VenueManagement.tsx`

### 技术更新 🔨

#### 布局技术要点
```tsx
// 固定滚动布局标准模式
<div className="flex flex-col h-[calc(100vh-8rem)] md:h-[calc(100vh-7rem)]">
  {/* 固定区域 */}
  <div className="flex-shrink-0 space-y-6 pb-4">
    {/* 标题、搜索、筛选按钮等 */}
  </div>
  
  {/* 可滚动区域 */}
  <div className="flex-1 overflow-y-auto space-y-6 min-h-0">
    {/* 筛选器、内容列表等 */}
  </div>
</div>
```

#### 关键 CSS 类说明
- `h-[calc(100vh-8rem)]`：计算容器固定高度（减去导航栏高度）
- `flex-shrink-0`：防止固定区域被压缩
- `flex-1`：让滚动区域占据剩余空间
- `overflow-y-auto`：启用垂直滚动
- `min-h-0`：确保 flex 子元素正确计算滚动高度

#### 酒精度自动计算
- 在基本信息和菜单信息中都显示酒精度
- **计算公式**：
  ```
  酒精度 = (总酒精体积 / 总容量) × 100%
  总酒精体积 = Σ(原料体积 × 原料酒精度)
  ```

**计算示例**：
```
配料：
- 金酒 45ml (40%)
- 青柠汁 15ml (0%)
- 糖浆 10ml (0%)

计算：
总容量 = 45 + 15 + 10 = 70ml
总酒精 = 45 × 0.4 = 18ml
酒精度 = 18 / 70 × 100% = 25.7%
```

**技术实现**：
```javascript
useEffect(() => {
  const calculateVolumeAndAbv = async () => {
    let totalVolumeMl = 0;
    let totalAlcoholVolume = 0;

    for (const recipeIng of recipe.ingredients) {
      const ingredient = ingredients?.find(ing => ing.id === recipeIng.ingredientId);
      
      if (['ml', 'oz', 'cl'].includes(recipeIng.unit)) {
        const volumeInMl = convertToMl(recipeIng.quantity, recipeIng.unit);
        totalVolumeMl += volumeInMl;
        
        if (ingredient.alcoholContent) {
          totalAlcoholVolume += volumeInMl * (ingredient.alcoholContent / 100);
        }
      }
    }

    const abv = totalVolumeMl > 0 ? (totalAlcoholVolume / totalVolumeMl) * 100 : 0;
    
    setRecipe(prev => ({
      ...prev,
      totalVolume: Math.round(totalVolumeMl * 10) / 10,
      calculatedAbv: Math.round(abv * 10) / 10
    }));
  };

  calculateVolumeAndAbv();
}, [recipe.ingredients, ingredients]);
```
