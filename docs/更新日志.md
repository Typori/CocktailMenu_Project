## [1.0.8] - 2025-11-10

### 修复 🐛

#### 损耗率计算公式修正
- **问题**：损耗率定义不准确，导致单价计算错误
- **旧定义**：损耗率表示额外损耗，单价 = 价格 ÷ 数量 × (1 + 损耗率%)
- **新定义**：损耗率表示原料总数量会被损耗的比例
  - 实际可用数量 = 数量 × (1 - 损耗率%)
  - 单价 = 价格 ÷ (数量 × (1 - 损耗率%))
- **示例**：
  ```
  价格: ¥1, 数量: 100ml, 损耗率: 99%
  可用数量 = 100 × (1 - 99%) = 1ml
  单价 = ¥1 ÷ 1ml = ¥1.00/ml
  ```
- **影响文件**：
  - `src/utils/calculations.ts` - 修改 `calculateUnitPrice` 函数
  - `src/components/AddIngredientMasterDialog.tsx` - 修改UI显示公式
  - `src/db/database.ts` - 修复数据库迁移代码中的计算公式


### 技术更新 🔨

#### 损耗率计算函数重写
```typescript
// src/utils/calculations.ts
export function calculateUnitPrice(ingredient: Ingredient): number {
  if (ingredient.quantity === 0) return 0;
  const wastageRate = ingredient.wastageRate ?? 0;
  const usableQuantity = ingredient.quantity * (1 - wastageRate / 100);
  if (usableQuantity === 0) return 0; // 防止损耗率为100%时除以0
  return ingredient.price / usableQuantity;
}
```

```typescript
    if (hasUnsavedChanges && !isNavigatingRef.current) {

      e.returnValue = '';
      return '';

    setShowDialog(true);
    return;
  }
  originalPush.call(this, to, state);
```

#### 酒精度自动计算
- 在基本信息和菜单信息中都显示酒精度
- **计算公式**：
  ```
  酒精度 = (总酒精体积 / 总容量) × 100%
  总酒精体积 = Σ(原料体积 × 原料酒精度)
  ```

**计算示例**：
```
配料：
- 金酒 45ml (40%)
- 青柠汁 15ml (0%)
- 糖浆 10ml (0%)

计算：
总容量 = 45 + 15 + 10 = 70ml
总酒精 = 45 × 0.4 = 18ml
酒精度 = 18 / 70 × 100% = 25.7%
```

**技术实现**：
```javascript
useEffect(() => {
  const calculateVolumeAndAbv = async () => {
    let totalVolumeMl = 0;
    let totalAlcoholVolume = 0;

    for (const recipeIng of recipe.ingredients) {
      const ingredient = ingredients?.find(ing => ing.id === recipeIng.ingredientId);
      
      if (['ml', 'oz', 'cl'].includes(recipeIng.unit)) {
        const volumeInMl = convertToMl(recipeIng.quantity, recipeIng.unit);
        totalVolumeMl += volumeInMl;
        
        if (ingredient.alcoholContent) {
          totalAlcoholVolume += volumeInMl * (ingredient.alcoholContent / 100);
        }
      }
    }

    const abv = totalVolumeMl > 0 ? (totalAlcoholVolume / totalVolumeMl) * 100 : 0;
    
    setRecipe(prev => ({
      ...prev,
      totalVolume: Math.round(totalVolumeMl * 10) / 10,
      calculatedAbv: Math.round(abv * 10) / 10
    }));
  };

  calculateVolumeAndAbv();
}, [recipe.ingredients, ingredients]);
```
