## 🍾 原料库存

### 核心功能

#### 1. 原料管理
- **添加原料**：中英文名称、分类、价格、数量、单位、酒精度
- **编辑原料**：修改任何原料信息
- **删除原料**：删除不再使用的原料
- **库存设置**：设置当前库存和最低库存阈值

#### 2. 原料分类
支持9种分类：
- 烈酒 (Spirit)
- 利口酒 (Liqueur)
- 其他酒类 (Other Alcohol)
- 香精 (Essence)
- 果汁 (Juice)
- 汽水 (Soda)
- 糖浆 (Syrup)
- 装饰品 (Garnish)
- 其他 (Other)

#### 3. 自动计算
- **单价计算公式**：价格 ÷ (数量 × (1 - 损耗率%))
- **损耗率定义**：原料总数量会被损耗的比例
  - 实际可用数量 = 数量 × (1 - 损耗率%)
  - 例如：100ml原料，损耗率5%，实际可用95ml
- **计算示例**：
  ```
  价格: ¥180, 数量: 700ml, 损耗率: 5%
  可用数量 = 700 × (1 - 5%) = 665ml
  单价 = ¥180 ÷ 665ml = ¥0.27/ml
  ```
- **性能优化**：单价在保存时计算一次并存入数据库，显示时直接读取

#### 4. 库存管理
- **快速调整**：+10/-10按钮
- **补满功能**：一键补充到最大值
- **库存警告**：当前库存 < 最低库存时显示⚠️
- **进度条**：可视化库存状态

#### 5. 筛选和搜索
- **搜索**：支持中英文名称搜索
- **分类筛选**：按原料分类筛选
- **显示数量**：每个筛选项显示对应数量

### 界面特点
- 紧凑的卡片布局
- 颜色编码分类
- 响应式网格（xl屏幕显示4列）

### 自动计算功能

#### 容量计算
```
总容量 = Σ(配料体积)
只计算：ml、oz、cl
不计算：dash、piece
```

#### 酒精度计算
```
酒精度 = (总酒精体积 / 总容量) × 100%
总酒精体积 = Σ(配料体积 × 原料酒精度)
```

**示例**：
```
莫吉托配方：
- 白朗姆酒 50ml × 40% = 20ml纯酒精
- 青柠汁 20ml × 0% = 0ml
- 糖浆 15ml × 0% = 0ml
- 苏打水 100ml × 0% = 0ml
总体积 = 185ml
ABV = 20ml / 185ml × 100% = 10.8%
```

#### 成本计算
```
总成本 = Σ(配料用量 × 原料单价)
```

**示例**：
```
莫吉托配方：
- 白朗姆酒 50ml × 0.23元/ml = 11.5元
- 青柠汁 20ml × 0.06元/ml = 1.2元
- 糖浆 15ml × 0.04元/ml = 0.6元
- 薄荷叶 10片 × 0.1元/片 = 1元
总成本 = 14.3元
```

## 🏪 店面管理

### 核心概念

#### 三层数据结构
```
全局层
├── 原料库 (ingredientMaster)
│   └── 存储原料基础信息(名称、分类、酒精度等)
└── 配方库 (recipes)
    └── 存储配方信息

店面层
├── 店面原料库 (venueIngredients)
│   └── 引用全局原料,添加价格、库存、供应商
└── 店面酒款 (venueRecipes)
    └── 引用全局配方,设置售价、上下架状态
```

#### 为什么要分层？
- **全局原料库**：统一管理所有原料的基础信息，避免重复录入
- **店面原料库**：每个店面可以有不同的供应商、价格和库存
- **灵活性**：同一款酒在不同店面可以有不同的售价

### 店面管理

#### 1. 创建店面
- **位置**：导航栏 → 店面管理
- **步骤**：
  1. 点击"新建店面"按钮
  2. 填写店面信息（名称、地址、描述）
  3. 点击"保存"
- **提示**：店面选择状态会自动保存，下次打开会记住上次选择的店面

#### 2. 编辑店面
- 修改店面信息
- 更新地址和描述

#### 3. 删除店面
- 删除店面
- 同时删除该店面的所有酒款和原料

#### 4. 标签页切换
- 在不同店面间切换
- 每个店面独立管理
- 两个标签页：酒款管理、原料库存

### 酒款管理（店面酒款标签页）

#### 1. 添加酒款
- **步骤**：
  1. 点击"添加酒款"按钮
  2. 从配方库选择要添加的酒款
  3. 点击"添加"
- **功能**：
  - 搜索配方
  - 自动排除已添加的酒款
  - 支持批量添加（"全部添加"按钮）

#### 2. 设置价格
- 点击"价格"按钮设置自定义售价
- 留空则使用配方默认售价
- 不同店面可以有不同价格

#### 3. 上架/下架
- 切换酒款可售状态
- 已下架酒款半透明显示
- 只有上架的酒款会出现在导出的菜单中

#### 4. 移除酒款
- 从店面移除酒款
- 不影响配方库

#### 5. 拖拽排序
- **进入排序模式**：点击"排序"按钮
- **拖动卡片**：整个卡片区域都可拖动，不会误选文字
- **调整顺序**：拖动到目标位置释放
- **保存排序**：点击"完成排序"按钮保存新顺序
- **取消排序**：点击"取消"按钮恢复原顺序
- **注意**：排序模式下禁用了卡片的点击和文字选择功能，专注于拖拽操作

#### 6. 筛选和搜索
- **搜索**：按名称搜索酒款
- **筛选**：
  - 风味标签筛选
  - 饮用类型筛选
  - 杯型筛选
  - 显示数量

#### 7. 根据库存刷新
- **位置**：酒款管理标签页 → 排序按钮左侧
- **功能**：根据当前店面的原料库存自动更新酒款的上下架状态
- **逻辑**：
  - 检查每款酒的所有配料
  - 如果所有配料都有库存（库存 > 0），则自动上架
  - 如果任何一个配料库存为0，则自动下架
- **使用场景**：
  - 补货后批量更新可售酒款
  - 原料用完后批量下架相关酒款
  - 快速同步库存状态和酒款状态
- **提示信息**：操作完成后会显示更新的酒款数量和上下架详情

#### 8. 导出菜单
- **位置**：酒款管理标签页 → 导出按钮
- **功能**：导出当前店面所有上架酒款为PDF
- **内容**：店面信息、酒款详情、价格、配料、制作方法
- **文件命名**：`店面名称_Menu.pdf`

### 原料库存管理（原料库存标签页）

#### 1. 批量添加原料（推荐）
- **步骤**：
  1. 点击"添加原料"按钮
  2. 在弹出的对话框中搜索或勾选原料
  3. 支持"全选"一次性选择所有原料
  4. 点击"添加 X 个原料"完成批量导入
- **默认值**：
  - 容量：750ml
  - 库存：750ml
  - 最低库存：200ml
  - 损耗率：5%
  - 价格：¥0（后续可编辑）
- **优势**：
  - 快速导入多个原料，无需逐个填写
  - 默认值适合大多数场景
  - 添加后可单独编辑每个原料的详细信息

#### 2. 编辑原料详情
- **步骤**：
  1. 在原料列表中点击"编辑"按钮
  2. 修改店面特定信息：
     - 总价格：采购总价
     - 数量：采购数量（如750ml）
     - 当前库存：实际库存量
     - 最低库存预警：低于此值会显示警告
     - 损耗率：默认5%
     - 供应商：供应商名称或联系方式
     - 备注：其他说明
  3. 点击"更新"保存
- **自动计算**：
  - 单位价格 = 总价格 ÷ 数量
  - 例如：¥180 / 750ml = ¥0.24/ml

#### 3. 快速库存操作
每个原料卡片上提供四个操作按钮（从左到右）：
- **补满**：一键将库存补充到该原料的默认数量
- **清空**：一键将库存清零
- **编辑**：编辑原料详细信息
- **删除**：删除该原料

#### 4. 批量库存操作
在原料库存标签页顶部提供两个批量操作按钮：
- **补满库存**：将所有原料的库存补满到默认数量
- **清空库存**：清空所有原料的库存（需确认）

#### 5. 库存预警
- 设置原料的"最低库存预警"
- 当"当前库存"低于预警值时：
  - 显示橙色警告图标
  - 顶部显示低库存数量徽章
- 及时补货

#### 6. 功能特性
- ✅ 批量添加原料（多选）
- ✅ 搜索原料
- ✅ 按分类筛选
- ✅ 拖拽排序
- ✅ 低库存预警（橙色警告图标）
- ✅ 快速库存操作（补满/清空）
- ✅ 批量库存操作
- ✅ 编辑/删除原料
- ✅ 自动排除已添加的原料
- ✅ 自动计算单位价格

#### 场景1：新开一家店
1. 创建店面

   - 点击"添加原料"
   - 勾选所有需要的原料（可使用"全选"）
   - 一键添加，使用默认值
3. 逐个编辑原料，设置实际价格和库存
4. 从配方库添加要售卖的酒款

6. 导出菜单

**💡 提示**：批量添加后再编辑，比逐个添加快得多！

#### 场景2：不同店面不同价格
**示例**：市中心店和郊区店

1. 在"市中心店"添加金酒：
   - 价格：¥200 / 700ml
   - 售价：¥68/杯

2. 在"郊区店"添加同样的金酒：
   - 价格：¥180 / 700ml（供应商不同）
   - 售价：¥58/杯（定价策略不同）

#### 场景3：季节性菜单
1. 添加季节性酒款到店面
2. 季节结束后点击"下架"
3. 下个季节再点击"上架"
4. 无需删除，保留历史数据

## 📄 PDF导出

### 单个配方导出

#### 使用位置
- **页面**：配方查看页面
- **按钮位置**：页面右上角，收藏按钮的左侧
- **按钮图标**：📥 导出（下拉菜单）

#### 导出选项
1. **完整版PDF**（含价格、成本等）
   - 配方名称（中英文）
   - 配方图片（如有）
   - 基本信息（杯型、容量、酒精度、成本、售价）
   - 风味标签
   - 酒款描述
   - 配料清单（含用量和酒精度）
   - 制作步骤
   - 备注信息

2. **简化版PDF**（仅原料和步骤）
   - 配方名称（中文）
   - 配方名称（英文）
   - 菜单名称（默认）
   - 原料列表（名称和用量）
   - 制作步骤
   - **特点**：简洁清爽，适合厨房或吧台使用

#### 使用方法
1. 打开任意配方的查看页面
2. 点击右上角的"导出"下拉按钮
3. 选择"完整版PDF"或"简化版PDF"
4. PDF文件将自动下载

#### 文件命名
- 完整版：`配方名称.pdf`（如：`莫吉托.pdf`）
- 简化版：`配方名称_简化版.pdf`（如：`莫吉托_简化版.pdf`）

### 店面酒单导出

#### 使用位置
- **页面**：店面酒款管理页面
- **按钮位置**：操作栏，排序按钮的右侧
- **按钮图标**：📥 导出（下拉菜单）

#### 导出选项
1. **完整版酒单**（含价格、成本等）
   - 店面名称、地址、描述
   - 所有上架酒款列表
   - 每款酒包含：
     - 酒款名称和价格
     - 英文名称
     - 配方图片（如有）
     - 基本信息（容量、酒精度、杯型、饮用类型）
     - 风味标签
     - 酒款描述
     - 配料列表
     - 制作步骤
   - 原料汇总清单（按类别分组）

2. **简化版酒单**（仅原料和步骤）
   - 所有上架酒款
   - 每款酒包含：
     - 酒款名称（中文）
     - 酒款名称（英文）
     - 菜单名称（默认）
     - 原料列表（名称和用量）
     - 制作步骤
   - **特点**：每个配方单独一页，格式统一，适合厨房或吧台使用

#### 导出规则
- ✅ 只导出上架的酒款（isAvailable = true）
- ✅ 按照displayOrder排序
- ✅ 自动分页
- ✅ 专业排版
- ✅ 每个配方独立一页（简化版）
- ✅ 格式完全一致（简化版）

#### 使用方法
1. 进入店面酒款管理页面
2. 选择要导出的店面（通过标签页切换）
3. 点击"导出"下拉按钮
4. 选择"完整版酒单"或"简化版酒单"
5. PDF文件将自动下载

#### 文件命名
- 完整版：`店面名称_酒单.pdf`（如：`市中心店_酒单.pdf`）
- 简化版：`店面名称_简化版酒单.pdf`（如：`市中心店_简化版酒单.pdf`）

#### 注意事项
- 如果店面没有上架的酒款，导出按钮会被禁用
- 导出的PDF会显示当前日期
